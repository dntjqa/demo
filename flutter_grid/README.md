# 3x3 Grid Flutter 예제

이 예제는 3x3 그리드 각 칸에 명칭을 입력할 수 있는 간단한 Flutter 화면을 제공합니다. `flutter_grid/lib/main.dart`를 Flutter 프로젝트 루트로 사용하면 바로 실행할 수 있습니다.

## 실행 방법
1. Flutter SDK가 설치되어 있어야 합니다.
2. 프로젝트 루트에서 의존성을 받습니다.
   ```bash
   flutter pub get
   ```
3. 에뮬레이터나 연결된 기기에서 앱을 실행합니다.
   ```bash
   flutter run
   ```

앱이 실행되면 그리드 각 칸에 원하는 명칭을 입력할 수 있습니다.
